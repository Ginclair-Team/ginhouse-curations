# Curated Agent Skills

A hand-picked list of agent skills, grouped by job. I did not write these and I do not maintain them. Credit belongs to the original authors, and each skill keeps its own license.

- **Included skills** are unmodified copies of permissively licensed skills (each folder keeps its `LICENSE`).
- **Linked skills** are not copied. Each category README gives the command that installs them from the author's repo, so you always get the author's current version.

## Install

```bash
# the included skills
npx skills@latest add Ginclair-Team/ginhouse-skills

# the linked skills: run the commands listed in each category README
```

Agents: after the first command, read `skills/*/README.md` and run every `npx skills add ... --skill ...` command listed there.
