# repo-plumbing

Repo setup, git guardrails, and scaffolding.

| Skill | What it does | Install / source |
|---|---|---|
| setup-pre-commit | Husky and lint-staged with typecheck and tests. | `npx skills add mattpocock/skills --skill setup-pre-commit` |
| git-guardrails-claude-code | Hooks that block destructive git commands. | `npx skills add mattpocock/skills --skill git-guardrails-claude-code` |
| setup-matt-pocock-skills | Configure tracker, labels, and docs for these skills. | `npx skills add mattpocock/skills --skill setup-matt-pocock-skills` |
| setup-ts-deep-modules | dependency-cruiser rules for deep modules. | `npx skills add mattpocock/skills --skill setup-ts-deep-modules` |
| scaffold-exercises | Exercise folders with problems and solutions. | `npx skills add mattpocock/skills --skill scaffold-exercises` |
