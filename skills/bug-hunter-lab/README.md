# bug-hunter-lab

Debugging, testing, review, and building from a spec.

| Skill | What it does | Install / source |
|---|---|---|
| diagnosing-bugs | Reproduce, isolate, and confirm hard bugs. | `npx skills add mattpocock/skills --skill diagnosing-bugs` |
| tdd | Test-first red-green-refactor. | `npx skills add mattpocock/skills --skill tdd` |
| code-review | Review changes against standards and the spec. | `npx skills add mattpocock/skills --skill code-review` |
| migrate-to-shoehorn | Move test type assertions to shoehorn. | `npx skills add mattpocock/skills --skill migrate-to-shoehorn` |
| implement | Build a piece of work from a spec or tickets. | `npx skills add mattpocock/skills --skill implement` |
| rust-async-patterns | Tokio, async traits, and concurrency in Rust. | `npx skills add wshobson/agents --skill rust-async-patterns` |
