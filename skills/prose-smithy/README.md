# prose-smithy

Writing and teaching: shape raw material, write for agents, remove AI tells.

| Skill | What it does | Install / source |
|---|---|---|
| writing-for-agents | Write skills, AGENTS.md, and CLAUDE.md. | `npx skills add mattpocock/skills --skill writing-for-agents` |
| writing-fragments | Mine raw notes with no structure yet. | `npx skills add mattpocock/skills --skill writing-fragments` |
| writing-beats | Assemble material into a journey of beats. | `npx skills add mattpocock/skills --skill writing-beats` |
| writing-shape | Shape beats into an article. | `npx skills add mattpocock/skills --skill writing-shape` |
| teach | Teach a concept within the workspace. | `npx skills add mattpocock/skills --skill teach` |
| wait-what | Re-pitch a message that did not land. | `npx skills add mattpocock/skills --skill wait-what` |
| [humanizer](humanizer/SKILL.md) | Rewrite AI-sounding prose without changing its meaning. | Included here. MIT, by see its LICENSE. |
