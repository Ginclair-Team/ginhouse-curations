# keyframe-forge

Motion graphics and video: build, render, and edit HyperFrames videos and slideshows.

| Skill | What it does | Install / source |
|---|---|---|
| hyperframes | Main workflow for making and rendering HTML-based video. | `npx skills add heygen-com/hyperframes --skill hyperframes` |
| hyperframes-cli | CLI to scaffold, check, preview, and render. | `npx skills add heygen-com/hyperframes --skill hyperframes-cli` |
| hyperframes-registry | About 450 ready-made blocks: transitions, titles, captions, charts. | `npx skills add heygen-com/hyperframes --skill hyperframes-registry` |
| remotion-to-hyperframes | Port Remotion, Lottie, or canvas animation and check it frame by frame. | `npx skills add heygen-com/hyperframes --skill remotion-to-hyperframes` |
| slideshow | Live presentations with fragments and speaker notes. | `npx skills add heygen-com/hyperframes --skill slideshow` |
| media-use | Music, voiceover, images, and colour grades for video. | `npx skills add heygen-com/hyperframes --skill media-use` |
| figma | Bring Figma frames and brand tokens into a video. | `npx skills add heygen-com/hyperframes --skill figma` |
| [lemo-opuscar](lemo-opuscar/SKILL.md) | Short films in named styles such as watercolor and ukiyo-e. | Included here. MIT, by LemoLab. |
