# blueprint-forge

Planning and specs: turn ideas into specs, tickets, and decisions before code.

| Skill | What it does | Install / source |
|---|---|---|
| to-spec | Publish a spec from the current conversation. | `npx skills add mattpocock/skills --skill to-spec` |
| to-tickets | Split a plan into tracer-bullet tickets with blocking links. | `npx skills add mattpocock/skills --skill to-tickets` |
| to-questionnaire | Turn an open decision into a questionnaire. | `npx skills add mattpocock/skills --skill to-questionnaire` |
| grill-with-docs | Relentless interview that also records ADRs and a glossary. | `npx skills add mattpocock/skills --skill grill-with-docs` |
| research | Primary-source research saved as Markdown. | `npx skills add mattpocock/skills --skill research` |
| triage | Move issues and PRs through triage states. | `npx skills add mattpocock/skills --skill triage` |
| wayfinder | Map work too large for one agent session. | `npx skills add mattpocock/skills --skill wayfinder` |
| egm | Elephant-Goldfish spec workflow with isolated reviewers. | https://github.com/google/elephant-goldfish-model |
